## 🚀 Portability: How to Continue
This project is saved and ready for a new chat. To restore it:
1.  **Upload `rebuild_project.txt`**
2.  **Upload `AI_Trading_Guardian.html`**
3.  **Upload `README.md`**

### Command to Restore:
```bash
python rebuild_project.txt
```
This will recreate the `trading_bot/` folder and all logic engines exactly as they are now.

## 📈 Functional Features
- **Pro Charting:** High-fidelity candlesticks with real-time price action.
- **Market Selection:** Dropdown menu to switch between Crypto (BTC/ETH/SOL) and Stocks (AAPL/TSLA).
- **Strategy Intel:** Live RSI(14) and EMA(20) calculation and AI Sentiment signals.
- **Sentinel Guardrails:** Numeric inputs for Profit Caps, Loss Floors, and Trailing Stops.
- **Kill Switch:** System automatically terminates all bot activity if a risk parameter is breached.
